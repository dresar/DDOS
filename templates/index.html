Untuk Edukasi & Testing Keamanan Jaringan

🔍 Apa itu DDOS (Distributed Denial of Service)?

DDOS (Distributed Denial of Service) adalah serangan cyber yang bertujuan untuk membuat layanan online menjadi tidak dapat diakses dengan cara membanjiri server target dengan jumlah request yang sangat besar secara bersamaan dari banyak sumber yang berbeda.

🎯 Konsep Dasar DDOS

1. Denial of Service (DoS):
Serangan yang membuat layanan tidak dapat diakses oleh pengguna yang sah. Biasanya dilakukan dari satu sumber (single source).

2. Distributed Denial of Service (DDoS):
Versi yang lebih canggih dimana serangan dilakukan dari banyak sumber secara bersamaan, membuat serangan lebih sulit dihentikan dan lebih efektif.

⚙️ Proses Serangan DDOS

Serangan DDOS umumnya mengikuti proses berikut:

  1. Persiapan:
    • Attacker mengidentifikasi target (server, website, atau layanan)
    • Menyiapkan botnet (jaringan komputer yang terinfeksi) atau menggunakan multiple sources
    • Mengkonfigurasi tools untuk mengirim request secara bersamaan
  2. Inisiasi Serangan:
    • Mengirim banyak request HTTP/HTTPS ke server target secara bersamaan
    • Menggunakan multiple threads atau connections untuk meningkatkan volume
    • Mengurangi delay antar request untuk memaksimalkan throughput
  3. Efek pada Target:
    • Server menjadi overload karena terlalu banyak request yang harus diproses
    • Bandwidth jaringan habis karena traffic yang sangat tinggi
    • Resource server (CPU, RAM) habis sehingga tidak bisa melayani request normal
    • Layanan menjadi lambat atau tidak dapat diakses sama sekali
  4. Deteksi & Mitigasi:
    • Server dapat mendeteksi pola traffic yang tidak normal
    • Rate limiting diterapkan untuk membatasi request per IP
    • Firewall atau DDoS protection service dapat memblokir traffic mencurigakan

🌐 Manipulasi IP Address

Dalam serangan DDOS, attacker sering menggunakan teknik manipulasi IP address untuk menyembunyikan identitas dan membuat serangan lebih efektif:

1. IP Spoofing:

Teknik mengubah source IP address dalam packet header untuk menyembunyikan identitas asli. Dalam tool ini, kita menggunakan HTTP headers untuk simulasi:

X-Forwarded-For: 192.168.1.100
X-Real-IP: 10.0.0.50

Catatan: Header ini hanya untuk demonstrasi. IP spoofing sebenarnya memerlukan akses level rendah ke network stack dan tidak dapat dilakukan hanya dengan HTTP headers biasa.

2. Random IP Generation:

Tool ini dapat menghasilkan random IP address untuk setiap request melalui HTTP headers. Ini membantu dalam:

  • Menyembunyikan pola serangan
  • Membuat rate limiting berdasarkan IP menjadi kurang efektif
  • Menyimulasikan serangan dari banyak sumber yang berbeda

3. Distributed Sources:

Serangan DDOS yang sesungguhnya menggunakan banyak komputer yang berbeda (botnet) dengan IP address yang berbeda-beda. Ini membuat:

  • Serangan lebih sulit dihentikan (tidak bisa hanya block satu IP)
  • Traffic terlihat seperti berasal dari banyak pengguna normal
  • Volume serangan bisa jauh lebih besar

🛡️ Cara Melindungi dari DDOS

  • Rate Limiting: Membatasi jumlah request per IP address dalam periode waktu tertentu
  • DDoS Protection Service: Menggunakan layanan seperti Cloudflare, AWS Shield, dll
  • Load Balancing: Mendistribusikan traffic ke multiple servers
  • Monitoring & Alerting: Memantau traffic patterns untuk mendeteksi anomali
  • Firewall Rules: Memblokir IP address yang mencurigakan
  • Scaling Resources: Meningkatkan kapasitas server untuk menangani traffic spike

📊 Bagaimana Tool Ini Bekerja?

Tool ini mensimulasikan serangan DDOS dengan cara:

  1. Multi-threading: Menggunakan banyak thread untuk mengirim request secara bersamaan
  2. Concurrent Requests: Setiap thread mengirim banyak request secara berurutan
  3. IP Spoofing (Opsional): Menggunakan random IP dalam HTTP headers untuk setiap request
  4. Monitoring: Melacak statistik seperti total request, success rate, dan rate limiting

⚠️ Penting untuk Dipahami:
Tool ini adalah untuk edukasi dan testing di lingkungan sendiri. Menggunakan teknik serupa pada server yang bukan milik Anda adalah ilegal dan dapat mengakibatkan konsekuensi hukum yang serius.
